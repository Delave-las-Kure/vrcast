# Что нового

Версия приложения — одно число в `src-tauri/Cargo.toml`. Каждый установщик, который получает
владелец, — новая версия: вторая цифра растёт, когда появляется новое, третья — когда только
исправлено. Сборку внутри версии называют коммит и его дата (окно «О программе»). Метка в git —
`v<версия>`, её сообщение — этот же раздел.

## 0.2.0 — 2026-10-09

- **Один экран «Видео» вместо четырёх вкладок.** Добавил файлы — план (ступени, размер, время) —
  «Старт» — дальше само: замер, кодирование, заливка, нарезка, проверка, ссылка. Каждый этап виден
  на карточке. После перезапуска приложения видео продолжает с того места, где остановилось.
- «Ступени» в карточке: можно поправить, недостающее домеряется само.
- Библиотека: «Собрать набор» у старого фильма; «Заменить» при занятом имени; файлы ступеней
  удаляются вместе с фильмом.
- Пауза одна — в карточке и в «Задачах». «Убрать» и удаление сервера сначала останавливают работу.
- Короче тексты: ошибка — одна строка и «Подробнее».
- Исправлено: «Старт всех» останавливал все видео, кроме одного; редкое «файл не найден на
  сервере» при нескольких видео сразу; полоса «Кодирование» прыгала со 100 % на 0 %.
- Окно «О программе» показывает сборку: коммит и его дату.
