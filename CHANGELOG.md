# Что нового

Версия приложения — одно число в `src-tauri/Cargo.toml`. Каждый установщик, который получает
владелец, — новая версия: вторая цифра растёт, когда появляется новое, третья — когда только
исправлено. Сборку внутри версии называют коммит и его дата (окно «О программе»). Метка в git —
`v<версия>`, её сообщение — этот же раздел.

## 0.3.0 — 2026-10-09

- **Ссылки готового фильма:** «Авто» и по ссылке на каждое качество (HLS) — в карточке «Готово» и
  в библиотеке. Рядом — памятка для друзей про «Allow Untrusted URLs».
- **На сервере только набор:** отдельные mp4 ступеней удаляются после проверки; для старых
  фильмов — «Лишние файлы mp4 — Удалить».
- **Звук:** если дорожек несколько, приложение спрашивает, какую взять. **Субтитры:** можно
  выбрать дорожку, она вжигается в картинку.
- **Замер качества** — тем же способом, что и кодирование; старые замеры удалены, фильмы
  замеряются заново. HDR-фильмы без пометки цветов больше не падают.
- **Скорость отправки** — один выбор рядом со «Старт всех», для всей заливки.
- **Сервер:** серверная часть версии 2 — «Обновить» на карточке. После «Заменить» по старой
  ссылке приходит новое. Caddy ставится с GitHub (старое хранилище стало платным). Поле
  «Тариф, Мбит/с».
- **Зрители и диагностика честнее:** «в порядке» только при известных цифрах; «не успевает»;
  ограничение говорит, что подействует после перезапуска видео у зрителя; «почему тормозит»
  смотрит живое соединение.
- **Мастер сервера:** ошибку порта или парольной фразы можно исправить прямо в нём.
- Исправлено: редактор «Ступени» ронял окно; странные ступени «1060p»; повторы строк в окне
  выхода и «Задачах»; пустые записи в библиотеке после отмены.

## 0.2.0 — 2026-10-09

- **Один экран «Видео» вместо четырёх вкладок.** Добавил файлы — план (ступени, размер, время) —
  «Старт» — дальше само: замер, кодирование, заливка, нарезка, проверка, ссылка. Каждый этап виден
  на карточке. После перезапуска приложения видео продолжает с того места, где остановилось.
- «Ступени» в карточке: можно поправить, недостающее домеряется само.
- Библиотека: «Собрать набор» у старого фильма; «Заменить» при занятом имени; файлы ступеней
  удаляются вместе с фильмом.
- Пауза одна — в карточке и в «Задачах». «Убрать» и удаление сервера сначала останавливают работу.
- Короче тексты: ошибка — одна строка и «Подробнее».
- Исправлено: «Старт всех» останавливал все видео, кроме одного; редкое «файл не найден на
  сервере» при нескольких видео сразу; полоса «Кодирование» прыгала со 100 % на 0 %.
- Окно «О программе» показывает сборку: коммит и его дату.
